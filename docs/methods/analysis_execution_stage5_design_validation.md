## Synthetic Script 13b

`src/R/13b_validate_imputation_design_synthetic.R` generates every record,
covariate and survival outcome artificially; it never reads a participant-data
file or real analysis constants. The seed is 20261013. It uses 27,755 synthetic
participants, six cycles, 89 strata and 180 nested PSUs, including two artificial
three-PSU strata. Synthetic knots are p5=24, p35=40, p65=60 and p95=76; these are
software-test constants, not the study's frozen knots.

The six marginal missing counts match the audit (575, 48, 31, 19, 164, 147 in
visit order). Missing locations are simulated, with artificial dependence on
cycle and death. Exact joint missingness patterns, real cluster sizes, and
real covariate correlations are not reproduced. This distinction must remain
explicit when interpreting the test.

The revised initial validation (v2) uses three chains and two iterations. It is a test of
software and computational feasibility, not a demonstration of convergence.
It implements the accepted predictor matrix, 83 stratum indicators and 91 PSU
indicators, scaling, PMM settings and multinomial optimization limits.

Important code blocks:

1. The cumulative-hazard routine counts events and risk sets at sorted times;
   hand-calculated controls cover tied events/censors and 0.5-month follow-up.
2. The design coding checks rank 180 with intercept/cycle, constancy within PSU
   and full observed-row predictor rank for each imputation target.
3. The installed MICE 3.19.0 `polyreg` function is copied and instrumented to
   inspect its fitted model and predicted probabilities before drawing. No
   estimation or random-draw algorithm is replaced. A controlled test compares
   both draws and RNG state with the original. Deliberate diagnostic failures
   must be detected.
4. One-iteration continuation records BMI moments/quantiles and a proportion
   for every category/chain/iteration. A checkpoint is saved after iteration 1;
   iteration 2 is replayed from disk, then compared with the uninterrupted
   result and a multi-iteration continuation from initialization.
5. Invariant checks precede sequential synthetic survey-Cox fits and comparison
   of scalar Rubin variance/finite-df calculations with an independent formula.

All warnings during conditional fitting and continuation are hard failures.
Unexpected MICE logged events or predictor changes also stop the test. No
fallback to a simpler survey representation is automatic.

## Artifacts and computational plan

Successful-validation files are intended to use prefix `qc_13b_synthetic_design_v2`, with an upfront no-overwrite
check. Checkpoints and full validation state belong under `data/processed/`;
compact QC, categorical-fit diagnostics and traces belong under `output/tables/`.
After an unexpected interruption before the original iteration-2 checkpoint,
the synthetic validator was extended to save initialization and each complete
iteration. `--resume` loads the latest matching iteration checkpoint. This more
frequent synthetic checkpoint cadence does not change the proposed five-iteration
real-run cadence. The script verifies substantive checkpoint state and formula
contents before finalizing its filename; equivalent deserialized formula
environments are not required to have object identity. A small serialization
control passed. Explicit timezone initialization avoids an unrelated
`timedatectl` warning in this container.
The manifest records code/specification hashes, seed, RNG kind and package
versions. Three chains limit memory; no parallel computation is used.

The revised initial path has 36 conditional fits; replay has 18; the batch-equivalence
path has 36. Thus this two-iteration validation entails 90 conditional fits,
plus three synthetic Cox fits. Later 50-chain, 20-iteration real MI would entail
6,000 conditional fits before the 50 Cox fits. Runtime must be estimated from
measured full-dimension performance rather than Script 13's small smoke test.

Validation commands, from the repository root:

```sh
Rscript -e 'invisible(parse(file="src/R/12b_audit_imputation_design_support.R")); invisible(parse(file="src/R/13b_validate_imputation_design_synthetic.R"))'
# Both execution commands refuse existing output files; review/version first.
Rscript src/R/12b_audit_imputation_design_support.R
/usr/bin/time -v Rscript src/R/13b_validate_imputation_design_synthetic.R
# After interruption, with matching code/specification/session manifest:
Rscript src/R/13b_validate_imputation_design_synthetic.R --resume
git diff --check
```

Measured wall time was **26 min 29.15 s**, user CPU time 1,391.22 s and peak RSS
1,377,204 KiB (**1.31 GiB**), with no swap activity. A simple fit-count scaling
from 90 to 6,000 conditional fits gives roughly **25–30 hours** for 50 chains and

Cox fitting, diagnostic review or extensions. This is a planning estimate, not

load and different categorical convergence can change it substantially. A
five-iteration real-run checkpoint block could therefore span several hours;
review checkpoint cadence prospectively before preparing Script 14.

Two iterations cannot support the two five-iteration-window convergence review
from the accepted specification. Extended traces, observed/imputed distribution
and conditional-model review, category-proportion diagnostics, and restart
failure-case testing remain before real-data execution approval. This initial
software result does not establish MAR, compatibility with the substantive
model, or adequacy of the real-data imputation models. No real-data MICE, new
study estimate, Script 14, commit or push was performed.


### Interrupted and unsuccessful attempts

The original session was lost during the first iteration before a checkpoint
existed. On resumption, a strict RDS object-identity check was corrected to
compare substantive state rather than formula-environment identity. The
corrected serialization control passed before full-size execution.

The subsequent v1 full-size attempt completed nine multinomial fits, all with
optimizer convergence, and passed the no-logged-events check. It then stopped
on an overly strict predictor-matrix storage-type assertion: MICE had normalized
the integer matrix to double. Inspection of the initialization checkpoint
confirmed exact agreement of values and dimension names. The v2 script builds
the reference matrix as double, retaining strict equality without permitting
predictor deletion. This is a software correction, not a method change.

The v1 attempt took 273.48 seconds with peak RSS 1,042,128 KiB (about 0.994 GiB)
and no swap activity. Its initialization checkpoint, executed script, failure
log and resource record are preserved under `data/processed/` with the v1
prefix. No completed validation or study output was overwritten.

Given this measured cost, the initial synthetic implementation gate was reduced
from five to two iterations before any synthetic pooled effect was examined.
The real-data proposal of 20 iterations remains unchanged. This reduced smoke
test deliberately cannot assess convergence; extended synthetic diagnostics
remain a separate gate.
